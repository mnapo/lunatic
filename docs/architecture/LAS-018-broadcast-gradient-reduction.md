## LAS-018 - Broadcast Gradient Reduction

### Status

Accepted

### Context

Lunatic currently supports broadcasting during forward elementwise operations.

Example:

```lua
A.shape = {3}
B.shape = {1}

A + B

Result shape:

{3}
```

During forward execution, smaller tensors are expanded logically to match the output shape.

However, during Autograd backward propagation, the gradient produced by the operation has the output shape. The original operands require gradients matching their original shapes.

Example:

```lua
Forward:

B:

{1}

broadcast

{3}


Backward:

gradient:

{3}

must become:

{1}
```

A mechanism is required to reverse the broadcasting transformation.

### Decision

Introduce a broadcast gradient reduction operation:

```lua
broadcast.reduce_gradient(
    gradient,
    target_shape
)
```

This operation receives:

- The gradient tensor generated by backward propagation.
- The original shape of the operand.

It returns a tensor whose shape matches `target_shape`.

### Algorithm

The operation follows these steps:

```lua
1. Normalize target_shape to the gradient dimensionality.

2. Detect dimensions expanded during broadcasting.

3. Reduce the gradient along those dimensions.

4. Restore the original target shape.

5. Return the reduced gradient tensor.
```

### Broadcast Axis Detection

Broadcasted dimensions are detected by comparing shapes from the right.

Example:

```lua
Gradient shape:

{2,3,4}

Original shape:

{1,3,1}
```

Comparison:

```lua
axis 3:

4 vs 1

reduce


axis 2:

3 vs 3

keep


axis 1:

2 vs 1

reduce
```

The reduction axes are:

```lua
{1,3}
```

### Reduction Strategy

Gradient reduction must reuse existing tensor reduction primitives.

The operation should rely on:

```lua
reduction.sum_axis()
```

rather than implementing separate accumulation logic.

Example:

```lua
gradient:

{2,3,4}

reduce axis 3

↓

{2,3,1}

reduce axis 1

↓

{1,3,1}

reshape

↓

original shape
```

### Shape Restoration

After reducing broadcast dimensions, the result must be reshaped to exactly match the original operand shape.

Example:

```lua
Reduced:

{1,3,1}

Target:

{3}

↓

reshape

↓

{3}
```

### Autograd Interaction

This operation belongs to the mathematical broadcasting layer.

It should not create Autograd nodes.

Individual operations are responsible for creating their backward functions.

Example:

```lua
add.backward()

gradient_a =
broadcast.reduce_gradient(
    gradient,
    input_a.shape
)


gradient_b =
broadcast.reduce_gradient(
    gradient,
    input_b.shape
)
```

### Implementation Constraints

The implementation must:

- Support arbitrary tensor dimensions.
- Reuse existing shape utilities.
- Reuse existing reduction primitives.
- Avoid operation-specific broadcasting logic.
- Preserve Lunatic's tensor abstraction.

### Future Extensions

This design prepares the library for:

- Broadcasting gradients in all elementwise operations.
- Multi-dimensional neural network operations.
- Automatic shape transformations.
- More advanced tensor algebra.
